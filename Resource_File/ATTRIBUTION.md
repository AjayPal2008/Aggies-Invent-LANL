# Learning resource attribution

The four article PDFs, cleaned text files and extracted knowledge JSON files are
derived from Wikipedia articles. The extracted JSON metadata specifies **CC BY-SA
4.0** and identifies the following source URLs:

| Article | URL |
|---|---|
| Computer security | https://en.wikipedia.org/wiki/Computer_security |
| Ionizing radiation | https://en.wikipedia.org/wiki/Ionizing_radiation |
| Nuclear fission | https://en.wikipedia.org/wiki/Nuclear_fission |
| Nuclear reactor | https://en.wikipedia.org/wiki/Nuclear_reactor |

Original contributors and revision histories are available through each article's
history page. Preserve source attribution and share-alike obligations for adapted
material. This records the existing supplied attribution, not an independent
license audit of every embedded image or third-party asset in the PDFs.

Changes made by this project: PDF-to-text extraction, removal of reference/end
matter and recurring page margins, structured summaries and concept extraction.
Generated diagnostic questions are adaptations requiring manual factual review.
No diagnostic bank, learner records or private debug responses are distributed
with these resource assets. The synthetic test bank is explicitly test-only.
